# 📋 AppTrack – Job & Internship Application Tracker

> A sleek, Kanban-style tracker for students managing internship and job applications — built with vanilla HTML, CSS & JavaScript.

🔗 **[Live Demo](https://calix1008.github.io/AppTrack/)**

![Status](https://img.shields.io/badge/Status-Live-brightgreen) ![License](https://img.shields.io/badge/License-MIT-blue) ![Made with](https://img.shields.io/badge/Made%20with-HTML%2FCSS%2FJS-orange)

## ✨ Features

- **Kanban Board** — Drag & drop cards across Applied → Interviewing → Offer → Rejected
- **Table View** — Sortable, filterable tabular list of all applications
- **Analytics & Funnel Dashboard** — Visual conversion funnel, weekly velocity timeline, type distribution, and key hiring insights
- **Company Logos & Smart Avatars** — Automatic high-res company logo fetching with gradient initials fallback
- **Follow-up & Attention Alert Banner** — Prominent reminder banner for overdue follow-ups and deadlines due today
- **Data Portability (JSON & CSV)** — Export to JSON or Excel-compatible CSV, plus instant Import with merge/replace options
- **Live Stats** — Instant KPIs: total applications, response rate, offer conversion
- **Full CRUD Modal** — Add, edit, and delete applications with rich metadata (salary, links, locations, notes)
- **Search & Filter** — Instant search across company, role, location + status filters
- **LocalStorage Persistence** — Data survives page refreshes with zero backend required
- **Keyboard Shortcuts** — `Ctrl+N` to add, `Ctrl+K` to search, `Esc` to close

## 🚀 Getting Started

No build step or dependencies required — just open `index.html` in any browser.

```bash
git clone https://github.com/Calix1008/AppTrack.git
cd AppTrack
open index.html   # or double-click index.html in File Explorer
```
