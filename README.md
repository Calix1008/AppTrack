# 📋 AppTrack – Job & Internship Application Tracker

> A sleek, Kanban-style tracker for students managing internship and job applications — built with vanilla HTML, CSS & JavaScript.

🔗 **[Live Demo](https://your-username.github.io/apptrack)**

## ✨ Features

- **Kanban Board** — drag & drop cards across Applied → Interviewing → Offer → Rejected
- **Table View** — sortable, filterable list of all applications
- **Live Stats** — total applications, response rate, offer count
- **Full CRUD** — add, edit, and delete applications via a rich modal form
- **Search & Filter** — search by company/role, filter by status
- **Follow-up Reminders** — overdue follow-up dates are highlighted
- **LocalStorage Persistence** — data survives page refreshes, no backend needed
- **JSON Export** — download all your data at any time
- **Keyboard Shortcuts** — `Ctrl+N` to add, `Ctrl+K` to search, `Esc` to close

## 🚀 Getting Started

No build step required — just open `index.html` in any browser.

```bash
git clone https://github.com/your-username/apptrack.git
cd apptrack
open index.html   # or double-click it in File Explorer
```
